# Future Lesson Content

These files were moved here during the Lesson 01–04 reorganization. They contain good content that will be redistributed into upcoming lessons.

## Files and Where They'll Go

### ard01b_Task.md — Morse Code SOS
Uses functions (`dot()`, `dash()`) and timing. Good intermediate project.
**Possible home:** After the binary counter unit, as a standalone project lesson.

### ard01c_Task.md — LED Patterns and Serial Control
Introduces **Serial input** (`Serial.available()`, `Serial.read()`), reaction time game, and single-LED binary counter.
**Possible home:** Before the Binary Guessing Game — students need to understand Serial input before they can play the guessing game.

### ard_lesson05_Binary_Guessing_Game.md — Binary Guessing Game
Follow-on task to the binary counter. Uses `Serial.parseInt()`, `random()`, bitwise AND (`&`), and custom functions.
**Possible home:** ard05 — after students have learned Serial input.

### ard_lesson05_TEACHER_SOLUTIONS.md — Teacher Solutions
Contains solutions for the binary counter AND the guessing game.
**Note:** The binary counter solution was also copied to `ard04_binaryCounter/teacher/`.
